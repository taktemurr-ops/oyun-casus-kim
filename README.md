# Casus Kim? · Who’s the Spy?

Herkes mekânı biliyor, biri hariç

Telefon elden ele dolaşır: herkes aynı mekânı görür, casus ise sadece "Casus sensin!" yazısını. Sırayla birbirinize mekânla ilgili sorular sorun; casus belli etmeden mekânı bulmaya, diğerleri casusu yakalamaya çalışır. Oylamada casus yakalanırsa mekânı tahmin etme hakkı vardır.

Aynı telefonda sırayla oynanır; oyuncu adları, takımlar, süre, yaş paketi ve kendi kelimeler lobiden seçilir. 100.000 bölüm (tohumlanmış deste); her deste kurallara göre doğrulanır. Parti ve Aile merkez uygulamasının oyunu; ortak motor: [parti-motoru](https://github.com/taktemurr-ops/parti-motoru).
